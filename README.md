⚡ CyberCart 2026 – Cyber Monday Mega Sale

📌 Project Overview

CyberCart 2026 is a responsive e-commerce website designed for a Cyber Monday mega sale. It provides customers with an interactive shopping experience, including discounted products, special coupons, a shopping cart, simulated checkout, order tracking, and a sales dashboard.

This project is developed as a front-end demonstration using HTML, CSS, and JavaScript.

 Objectives

- Create an attractive and responsive shopping website.
- Display products with discounts and ratings.
- Provide an interactive shopping cart and checkout experience.
- Demonstrate coupon codes, loyalty points, and promotional offers.
- Display order tracking and sales statistics.

 Features

-  Product catalog with categories and search.
-  Discounted prices and flash sales.
-  Shopping cart with quantity controls.
-  Coupon vault and promotional codes.
-  Spin-to-win coupon feature.
-  Wishlist and product comparison.
-  Demo price alerts.
-  Simulated checkout and order tracking.
-  Customer reviews and ratings.
-  Sales dashboard with sample statistics.
-  Multiple themes: Cyber Neon, Light, Luxury Gold, and Ocean Blue.
-  Responsive layout for mobile and desktop.

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layouts, and responsive design
- JavaScript – Interactive features and shopping logic
- LocalStorage – Saving demo data in the browser

 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Explore the products, coupons, cart, reviews, and dashboard.

You can also use Visual Studio Code with the Live Server extension to run the website locally.

 Important Notes

- This is a front-end demonstration project.
- Product prices, reviews, and sales statistics are sample data.
- Payments are simulated; no real transactions are processed.
- Orders and other saved demo information are stored locally in the browser.
- This project does not include a production backend or database.
